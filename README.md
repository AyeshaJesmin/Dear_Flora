# 🌸 Dear Flora – Handmade Bouquet Store

**Dear Flora** is an online store for handmade bouquets, created to make gifting special and memorable.

🌐 **Live Website:** https://dearflora.netlify.app/

## ✨ Features

- Browse handmade bouquet collections.
- View individual product details.
- Add products to the shopping cart.
- Customize bouquets with personal preferences.
- Place orders through the checkout system.
- Submit customer inquiries through the contact form.
- Admin dashboard for product and order management.
- Store cart information using LocalStorage.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- LocalStorage
- Netlify
